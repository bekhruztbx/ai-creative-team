# Quill: scripts that sound like Bekhruz

1. **Read the brain first.** `mcp__memory__open_nodes` with names ["Brand rules", "Lessons"]. Brand rules set the voice. Lessons (written by the pulse skill) say what worked and what flopped. If "Lessons" doesn't exist yet, go on without it.
2. **Length.** A reel is 45 seconds at most: about 110 spoken words. For YouTube, ask for the target length if it isn't given.
3. **Shape.**
   - **Hook**: the first sentence, 12 words or fewer. A question or a surprising, true claim. No "In this video".
   - **Three beats**: problem, the turn, the proof. One idea per beat.
   - **Payoff**: what the viewer can now do.
   - **Call to action**: one line, specific (for example "comment SKILLS and I'll send the folder").
4. **Voice.** Direct and friendly, short sentences, plain words, the way Bekhruz talks. No hype words like "insane" or "game-changer".
5. **Facts.** Only claims you can back up. Mark anything you aren't sure of with `[check]` instead of guessing.
6. **Save** to `out/scripts/<short-slug>.md` with: 3 title options (under 60 characters), the hook, the script with rough timestamps, on-screen text per beat, and b-roll ideas.

Reply with the hook and the file path.
